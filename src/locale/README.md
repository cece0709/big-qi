# 界面翻译来源

固定中文界面文案及教学解析于 2026-09-18 使用 Google 翻译公开网页（https://translate.google.com/）取得英文、西班牙语、日语和韩语初稿，每种语言 916 条。未启用收费 API；应用运行时不向翻译服务传送棋局或学习记录。

translate.ts 对品牌名、象棋名称、难度、悔棋、将军、将死与逼和等常用术语作人工校订。机器翻译并不等同于母语棋类编辑审校；传统象棋杀法名称和较长解析仍适合请对应语言棋友复核。

messages.json 为离线文案包。模板中的 {0}、{1} 等占位符必须保留。棋子字面保持汉字；切换语言不重建棋局状态。新增中文文案需要同时补齐四语语言包。
