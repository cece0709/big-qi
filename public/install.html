← 打开弈见

一方棋局，随身相伴。

弈见提供网页版与可安装版（PWA），使用相同的棋局、教学、摆局研究与音效功能。

Windows / macOS 电脑

使用 Chrome 或 Edge 打开弈见。在地址栏安装图标或浏览器菜单中，选择“安装”或“将此网站安装为应用”，然后按照提示确认。

安卓手机

使用 Chrome 打开网站，点菜单 → 安装应用（或添加到主屏幕）。

iPhone / iPad

使用 Safari 打开网站，点分享 → 添加到主屏幕。如果出现“作为网页 App 打开”，请开启后添加。

离线使用与更新

首次联网打开并等待资源缓存完成，再从桌面图标打开即可离线使用核心棋局功能。首次未成功缓存时仍需要网络。重新联网后，新版就绪会显示更新按钮。

对局记录保留在本次运行会话中，关闭应用或刷新后会重置。可安装版不是独立的商店安装包，无需购买 AI 接口。
