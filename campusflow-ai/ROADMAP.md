# CampusFlow AI · 后续规划

以下仅为规划，不代表 V1 已实现。

## V1 设备验收

- 安卓 Expo Go SDK 55 与独立 APK 的完整闭环。
- 通知允许/拒绝、设备省电、长时间后台、进程关闭和重启恢复。
- 使用开发者自己的服务端密钥完成真实 AI 聊天与任务提取。
- 小屏、字体放大、键盘、读屏、返回键与可访问性。
- 公开代理部署前补认证、配额、按用户隔离限流与 HTTPS。

## V2 产品能力

| 方向 | 计划 | 关键前置工作 |
| --- | --- | --- |
| 多模态 | 图片、语音聊天 | 媒体授权、文件限制、删除与供应商适配 |
| AI | 多 AI 模型切换 | 扩展统一 Provider、能力和费用提示 |
| 系统任务 | Apple 提醒事项 | iOS 原生桥接、最小权限 |
| 健康集成 | Android Health Connect、Apple HealthKit | 明确授权、平台审核与敏感数据保护 |
| 健康记录 | 睡眠、步数、活动数据 | 完成健康集成；不作医疗诊断 |
| 个人空间 | 个人动态、书架、唱片架、相册 | 媒体管理、备份和清除 |
| 社交 | 好友、点赞 | 账号、屏蔽举报、隐私和反骚扰 |
| 个性化 | 角色、主题市集 | 内容审核、作者授权、导入安全 |
| 账号 | 云端同步、多设备登录 | 认证、冲突处理、数据删除与恢复 |
| 国际化 | 中英文切换 | 文案抽取、日期时间本地化 |
| 界面 | 深色模式 | 对比度与视觉回归 |

## 工程演进

1. 按数据规模考虑 AsyncStorage → SQLite，聊天历史分页。
2. 建立安卓端到端测试和 CI，覆盖安装、通知、后台与升级迁移。
3. 补充完整数据恢复、跨设备同步与本地图片迁移。当前 JSON 导出不能保证所有本地图片可跨设备访问。
4. 评估本地加密、应用锁定和操作系统备份策略。
5. 服务端增加认证、配额和可观测性，仍不记录完整私人请求正文。
