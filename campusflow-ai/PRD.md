# CampusFlow AI · 产品需求

版本 V1，2026-09-23。本文描述目标与验收要求；实现验证状态见 TESTING.md。

## 定位与用户

面向大学生的 AI 生活与学习执行助手，把聊天中的计划转成待办，用专注记录支持行动与复盘。核心用户包括需要安排课程、复习和日常生活的大学生，以及展示产品和移动端工程能力的作品集作者。

核心闭环：**人设 → 独立聊天 → 提取并确认任务 → 专注执行 → 本地统计**。

## 信息架构与视觉

| 底部标签 | 主要内容 |
| --- | --- |
| 聊天 | 当前 AI 人设、切换、独立消息、输入、人设管理 |
| 生活 | 顶部待办/专注切换，任务与计时操作 |
| 统计 | 每日/每周/每月，趋势、热力图、分类、比较 |
| 我的 | 人设、通知、主题背景、AI 模式、导出、清除、隐私、关于 |

默认简体中文，柔和浅色背景、通透卡片、大圆角、足够的文字对比度。支持纯色、渐变与用户选图背景。使用开源图标和原创组合，不复制第三方名称、头像、图片或完整布局。处理安卓安全区域、键盘和底部导航遮挡；关键操作需要加载、空状态、错误或完成反馈。

## V1 验收要求

### 人设与聊天

- 创建、编辑、删除、切换人设；字段包含名称、头像、身份、背景、性格、风格、回复长度、称呼、开场白、应做/不应做事项、手动长期记忆和时间戳。
- 至少两个明确标识的示例角色；示例角色不自动生成用户统计。
- 每个角色独立会话；支持人设 JSON 导入导出、消息编辑/复制/删除、清空。
- 人设组装 system prompt，安全规则优先于用户角色偏好。
- 支持流式/逐步显示、加载状态、重试、重新生成和滚动到最新消息。
- 默认 Mock；真实 API 必须经服务端代理；页面标识 AI 与生成内容提示。

### 聊天转任务

- 从消息操作触发提取；保存前进入编辑确认。
- 字段包含标题、日期、时间、分类、预计时长、源消息和角色关联。
- “明天下午三点复习高数一小时”对应明日、15:00、60 分钟、学习。
- 不确定的日期时间留空；不能因只有时间而擅自假定日期。

### 待办与专注

- 待办新增、编辑、删除、完成/恢复，支持分类、日期时间、预计时长、搜索、今天/即将到来/已完成筛选。
- 默认分类为学习、阅读、运动、休息、课程、其他；任务可关联专注。
- 本地提醒按需申请权限；拒绝权限不阻止保存任务。
- 25 分钟专注、5 分钟休息、自定义时长和秒表；开始、暂停、继续、结束、重置。
- 正常完成与提前中断都能保存实际时间，不能强制完成 25 分钟。
- 计时使用持久化时间戳，切换标签、后台恢复与重启后正确恢复。

### 统计与设置

- 今日专注、今日完成任务、连续使用天数；日/周/月；两种趋势、热力图、分类占比与前后 7 天比较。
- 统计来自本地记录，首次为空；只有主动加载示例数据才生成标记清晰的演示记录。
- 提供通知、主题/背景、AI 模式、数据导出和确认后删除全部数据。

## 工程与隐私

React Native、Expo、Expo Router、TypeScript strict、AsyncStorage 和 Node.js 代理。独立数据读取、写入、迁移和校验层。API Key 仅为服务端环境变量，日志不记录完整私人聊天。只在主动选图与开启提醒时申请相关权限，不读取通讯录、位置和健康数据。

提供 `/api/chat`、`/api/extract-task`、`/api/health`。基础安全规则拒绝违法和不适合未成年人的内容、不诱导依赖、不排斥现实关系，不提供医疗诊断、法律结论或投资保证。

## 完成定义

代码、锁文件、配置与文档可以继续开发；类型检查、Lint、单元测试和构建检查通过。安卓实际启动、扫码、API、通知、后台与重启需要真实设备验收。没有执行的环节须标记未验证，不能把 JS 打包等同于安卓 APK 运行。V2 不挤入 V1，详见 ROADMAP.md。
