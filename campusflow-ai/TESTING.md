# 测试与验证

## 自动化命令

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm check
```

当前自动化覆盖：

- 人设名称校验与安全 system prompt。
- 待办创建、编辑、完成和本地任务提取。
- 番茄钟暂停、继续、完成与后台时间戳恢复。
- 真实专注/完成任务统计与分类聚合。
- AsyncStorage 适配器的写入与重新读取。
- 旧版单一角色提醒设置迁移到多时段、语气、免打扰和多条通知标识。
- 旧版数据迁移后默认关闭应用访问与专注守护；应用范围变化会让已有确认失效。
- Mock AI 的流式回复与任务提取。
- NDJSON 分块解析。
- Node 代理的 `/api/health`、无密钥任务提取和无密钥聊天失败路径。

## 手工验证清单

在 Android Expo Go 或 development build 中验证前 1–9 项；第 10 项需要包含本地原生模块的独立 Android APK（EAS Preview）：

1. 创建、编辑、切换和删除 AI 人设；确认角色之间聊天独立。
2. Mock 聊天发送、停止、复制、删除、重试和转待办。
3. 待办新增、编辑、搜索、筛选、完成和删除。
4. 计时开始、暂停、恢复、提前结束、页面切换及后台后恢复。
5. 用户主动加载示例数据后，统计趋势、热力图和分类更新。
6. 允许/拒绝相册与通知权限，确认 App 显示可理解的反馈。
7. 无网络、错误的代理地址和未配置 API Key 时，确认 App 显示重试路径。
8. 在“我的 → 陪伴节奏”选择多个每日时段、不同消息语气和免打扰预设；测试消息应立即显示，全部时段落入免打扰时开启应显示调整提示。
9. 在“生活”检查“下一件事”卡片；点“去专注”后，关联任务应自动带入专注面板。

10. 在【我的 → 应用访问与专注守护】选择两个非系统应用，确认更改范围后之前确认会失效；连续完成两次确认，分别在 Android 系统页打开【使用情况访问】和【CampusFlow 专注守护】。返回后刷新状态，查看近 7 天所选应用时长。开启守护、启动番茄专注后打开已选应用，应回到桌面；暂停计时、结束计时、关闭守护或点击【暂停守护 5 分钟】后不应再触发。确认它不读取或显示应用内容。
