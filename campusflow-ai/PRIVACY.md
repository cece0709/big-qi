# CampusFlow AI · 隐私说明

版本 V1，2026-09-23。说明作品集项目的数据流与当前限制，未来公开上线需另行完善正式政策。

## 本地数据

默认 Mock 模式。人设、手动长期记忆、聊天、任务、专注记录、计时状态与设置通过 AsyncStorage 保存在本机。Mock 聊天与规则提取不向 AI 服务商发送内容。

AsyncStorage 不提供本项目层面的数据库加密；V1 没有账号和云同步。系统备份、调试工具、Root 等设备环境可能影响数据可访问性。不要在聊天或人设中填写密钥、密码或不必要的敏感资料。

## 真实 AI 模式

用户主动选择真实 API 模式后，请求经配置的 Node.js 代理发送到开发者选择的兼容 OpenAI 接口的供应商。

| 操作 | 发送内容 |
| --- | --- |
| 真实聊天 | 当前角色的文本设定、手动长期记忆、安全提示和当前会话上下文 |
| 真实任务提取 | 要转换的消息文字和当前日期参考 |
| 健康检查 | HTTP 请求及必要网络元数据 |

其他角色历史、任务列表、专注统计与图片不会因普通聊天自动发送；用户主动输入其中的信息时，会作为聊天文字处理。V1 不上传图片作为多模态附件。

代理不建立用户数据库，不主动持久化或完整打印私人聊天，请求内容在内存中转发。供应商的保留、训练、地域与删除政策以其服务条款为准，本项目不替供应商承诺零保留。部署者也需要检查平台、网关与反向代理的日志配置。

## 密钥与权限

AI API Key 只能在 `server/.env` 或服务端进程环境中。任何 `EXPO_PUBLIC_` 变量都会进入客户端，不得包含秘密。本地开发可用可信 LAN；共享部署应使用 HTTPS、身份验证与配额控制。V1 代理仅供个人开发演示，未提供用户鉴权。

- 相册：主动选择头像/背景时才发起系统选择或授权，取消与拒绝不影响默认界面。
- 通知：主动开启任务或角色消息提醒时申请；拒绝不阻止保存任务，可在系统设置重新开启。角色消息可由用户选择每日多个本地时段、消息语气和免打扰时间；使用选定人设的名称和本地文案，不会在后台实时调用 AI、读取其他应用使用情况或控制设备。
- 通讯录、定位、健康数据、麦克风、摄像头：V1 核心功能不使用或主动申请。

本地通知可能在锁屏显示任务文字或人设名称、开场白，用户可在系统中调整通知预览。

## 导出与删除

完整数据与单个人设可以导出 JSON，人设 JSON 可导入。导出为可读文字，包含本地图片引用；原生图片文件不保证随 JSON 导出或在其他设备可用。用户主动通过分享面板发送的副本不会随着本地删除自动删除。

“删除全部数据”经确认后清除 App 管理的业务数据和提醒，恢复初始状态。它不能撤回已经发送给供应商、已导出或进入系统备份的副本。V1 没有云端账号，因此没有云端账号删除接口。

## AI 边界

角色明确标识为人工智能，不能冒充真人。基础规则不允许诱导排他依赖、排斥现实关系或生成违法和不适合未成年人的内容。内容由 AI 生成，需要用户自行判断，不构成医疗诊断、法律结论或投资保证。系统提示词是基础防线，不能保证所有模型输出均正确或安全。
