## 功能
- 主界面一键切换中国象棋 / 国际象棋；切换保留各自棋局、页面与复盘记录，离开当前版本会暂停 AI。
- 首页、象棋对局、入门教学、教学棋局、残局闯关、复盘六个页面。
- 立体木质棋盘与棋子，拿起 / 移动 / 落子动画和木质音效。
- 合法落点、中文走法解释、悔棋、提示、本地双人对战。
- 自由摆局、移出与放回棋子；锁定后控制一方，由本地 AI 应战。
- 锁定前自动检查将帅、棋子位置、数量、先行方和是否无棋可走；有问题时可恢复标准开局、返回调整或继续非标准研究。
- 25 道互动残局与战术练习、46 条常见技巧，含分类查找、分步提示、逐步答案及中文解析。
- 国际象棋：8×8 棋盘、六种棋子教学、易位、吃过路兵、四种升变、10 道互动残局与解析、自定义摆局检查。
- 中国象棋独立 Worker 中最多三层搜索，并延伸检查吃子交换；侧栏解释目的、风险与成语比喻。
- PWA 安装入口、192 / 512 像素图标、离线资源缓存与更新提示。
- 全页面 Celia 署名、版权声明、第三方许可证。

## 结构
- src/chess：国际象棋界面、规则适配、独立分析 Worker、教学与残局。
- src/pages：六个功能页面。
- src/components：棋盘、页面标题、安装入口。
- src/game：规则、搜索、教学分析、音效与测试。
- scripts/pwa.ts：构建时生成离线资源清单及 Service Worker。
- public：插画、图标、安装说明、版权页面。

## 开发与构建
使用 Node.js 24 与 pnpm。
1. pnpm install
2. pnpm dev
3. pnpm build
4. node src/game/rules.test.ts
5. node src/game/teaching.test.ts
6. node scripts/test-pwa.mjs（先构建）
7. node src/game/puzzles.test.ts
8. node --import tsx src/chess/engine.test.ts

构建输出在 dist，可部署到支持 HTTPS 的静态托管服务。
PWA 仅在生产构建注册 Service Worker。开发模式不注册，避免缓存干扰修改。
现有 scripts/vite.mjs 使用 esbuild 的 WebAssembly 后端，兼容 Windows 沙箱。

## 网站版与安装版
打开正式网址即可使用网页版。在 Chrome / Edge 点击“安装弈见”或浏览器安装按钮。
iPhone / iPad 用 Safari 的分享菜单选择“添加到主屏幕”。详见 public/install.html。
首次联网打开并成功完成资源缓存后，可离线使用核心棋局功能。
PWA 是浏览器安装的应用，不是 EXE / APK 安装包。

## 当前边界
AI 在设备本地运行，不依赖付费 AI API；有限深度推荐不保证全局最优。
棋局和学习记录仍保存在当前运行会话中，刷新、重启或离开教学页后可能重置。
收录常见技巧及独立编排的练习，并不涵盖全部市售棋谱。中国象棋不含竞赛长将长捉、三次重复裁定。国际象棋由 chess.js 1.4.0 校验合法走法，本练习按三次重复和五十回合条件自动判和，不模拟比赛申诉流程；自定义摆局默认无易位与吃过路兵权利。多步题显示参考应对。
非标准研究只按基本走法移动，不校验将帅安全，也不进行正常胜负判定；正常对弈仍遵守原有规则。
本项目没有替用户办理软件著作权或商标登记。
